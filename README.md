# Python 影片自動批次壓縮工具 (Video Compressor)

這是一個使用 **Python** 結合 **FFmpeg** 開發的輕量化自動批次影片轉檔工具。專為處理大型螢幕錄影檔（Screen Recordings）設計，能有效幫影片「瘦身」並維持畫面清晰度。

## ✨ 主要功能特點
- **自動資料夾巡迴**：自動掃描指定資料夾內的所有影片，一個接一個完成批次處理。
- **智慧移動與清理**：壓縮完成後自動移至「壓縮完成」資料夾，並自動刪除原始大檔以節省磁碟空間。
- **高效能壓縮**：使用 H.264 (`libx264`) 與快速預設值 (`-preset fast`)，在畫質與轉檔速度取得最佳平衡。
- **720p 最佳化**：自動將高解析度影片縮放至 720p，限制 30 fps，完美適合教學與操作錄影。

## 📁 資料夾結構
請在專案根目錄或指定路徑下建立以下結構：
- `C:\Users\影片壓縮\待壓縮` （放置原始錄影檔）
- `C:\Users\影片壓縮\壓縮完成` （輸出壓縮後的檔案）

## ⚙️ 系統需求
- Python 3.x
- 已安裝 **FFmpeg** 並已加入系統環境變數 (PATH)
